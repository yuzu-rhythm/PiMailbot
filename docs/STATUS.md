# 機能状況

2026-10-27の開発スナップショットです。「実装あり」「開発環境で確認」「公開コピーで再確認」を分けています。

| 項目 | 実装 | 確認範囲 |
| --- | --- | --- |
| Gmail5アカウントの個別認証・新着通知 | あり | 開発環境で接続・通知を確認。公開コピーでは接続しない |
| 内容分類・ラベル保存 | あり | 開発環境で保存記録とGmailラベルの存在を確認 |
| 全アカウントへの共通7ラベル | 設定可能 | 開発環境で7種類の存在を確認。公開版は設定を同梱しない |
| 分類保存と保管の一括操作 | あり | Piへ配置・起動を確認。最新操作の端から端までは未確認 |
| 処理済み通知の削除 | あり | 開発環境で処理済み8件の通知不在を確認。今回の公開作業で削除しない |
| 取り消し・再通知 | あり | 処理前記録・復元経路あり。最新の内容分類込みの復元は未確認 |
| 直後の取り消しボタン | あり | 10分間、操作世代・許可対象を照合。最新の実操作は未確認 |

| Gemini要約 | 任意の実装あり | 架空文のAPI応答を開発環境で確認。実メールの自動要約は無効 |
